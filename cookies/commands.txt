Automation script to run the pipeline and show results
Run this single PowerShell script from anywhere. It uses the venv Python, runs the pipeline with a prompt/seed you can change, captures output, lists recent files, and prints a compact summary of the last storyboard.

powershell
# Save as run_pipeline.ps1 and run: .\run_pipeline.ps1
$root = "C:\projects\ai\content_bot"
$py = Join-Path $root ".venv\Scripts\python.exe"
$script = Join-Path $root "nodes\ai_lady\pipeline.py"
$out = Join-Path $root "pipeline_out.txt"
$err = Join-Path $root "pipeline_err.txt"

Set-Location $root

# change prompt/seed here if desired
$prompt = "soft girl morning"
$seed = 123

# run pipeline
& $py $script --prompt $prompt --seed $seed --pretty > $out 2> $err

# show errors if any
if ((Get-Item $err).Length -gt 0) {
  Write-Host "`n--- ERRORS ---`n" -ForegroundColor Yellow
  Get-Content $err -Raw
} else {
  Write-Host "`nNo stderr output.`n" -ForegroundColor Green
}

# print a short snippet of stdout
Write-Host "`n--- PIPELINE OUTPUT (snippet) ---`n"
Get-Content $out -Raw | Select-Object -First 1 | ForEach-Object { $_.Substring(0,[Math]::Min(2000,$_.Length)) }

# list recent storyboards and scenes
Write-Host "`n--- Recent storyboards ---`n"
Get-ChildItem .\nodes\ai_lady\storyboards -File -ErrorAction SilentlyContinue | Sort-Object LastWriteTime -Descending | Select-Object -First 5 Name,LastWriteTime | Format-Table -AutoSize

Write-Host "`n--- Recent scenes ---`n"
Get-ChildItem .\nodes\ai_lady\scenes -File -ErrorAction SilentlyContinue | Sort-Object LastWriteTime -Descending | Select-Object -First 5 Name,LastWriteTime | Format-Table -AutoSize

# print compact summary of last storyboard JSON
$last = Get-ChildItem .\nodes\ai_lady\storyboards -File -ErrorAction SilentlyContinue | Sort-Object LastWriteTime -Descending | Select-Object -First 1
if ($last) {
  $json = Get-Content $last.FullName -Raw | ConvertFrom-Json
  Write-Host "`n--- Storyboard summary ---`n"
  Write-Host ("Scene ID: " + $json.scene_id)
  Write-Host ("Duration: " + $json.duration_seconds + "s")
  Write-Host ("Location: " + $json.environment.location)
  Write-Host ("Character: " + $json.character.name + " — " + $json.character.action)
  Write-Host ("Saved: " + $last.FullName)
} else {
  Write-Host "`nNo storyboard files found.`" -ForegroundColor Yellow
}

Why requirements.txt matters
requirements.txt lists the Python packages your project needs so anyone (or CI) can install the exact dependencies with one command. It ensures reproducible environments, avoids “works on my machine” problems, and documents runtime needs (Azure SDK, MoviePy, Pillow, local TTS libs, etc.).
Short: it’s a single source of truth for what to pip install.
